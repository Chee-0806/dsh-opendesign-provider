## 补测试：白名单下拉 + 覆盖编辑器（`tests/settings-fields.test.ts`，22 个用例）

- **首次在 tests/ 里引入 DOM**：`happy-dom`（devDependency，不进产物，已验证 `lib/` 里 0 处引用）。
  React DOM 在首次求值时就锁定 `canUseDOM`，所以 `createRoot` 必须 **动态 import**，
  且要在 import 之前把 `window/document/Event/MouseEvent/PointerEvent/...` 用
  `Object.defineProperty` 装到 `globalThis`（`navigator` 在 Node 22 是只读 getter，直接赋值会抛）。
  同时设 `IS_REACT_ACT_ENVIRONMENT = true`，`act` 从 `react` 取（18.3 已有 `React.act`，
  不用 `react-dom/test-utils` 的弃用版）。
- **受控输入必须用原型上的原生 setter**：React 会在实例上 `defineProperty('value')` 做值追踪，
  直接赋值会被吞掉；`Object.getOwnPropertyDescriptor(HTMLInputElement.prototype,'value').set.call(el, v)`
  再派发 `input`（input）/`change`（select，用 `HTMLSelectElement.prototype`）才触发 onChange。
  checkbox 直接 `.click()` 即可（React 的 onChange 对 checkbox 由 click 事件驱动）。
