# 不显示金额，只保留成本档位

OpenDesign 官方不公布每百万 token 的美元单价，模型目录只给 `metadata.cost` 的 `low/medium/high` 档位词；commandcode 版那套「美元价表 + 峰谷计价 + 会话费用 `≈$` + 成本投影」在 OpenDesign 上没有数据来源。因此改造时整体删除金额维度（价表、峰谷、会话费用、成本投影），分析页只显示 token、速度、失败/重试与档位标签，不做任何美元折算。

**Considered Options**：用档位 × 倍率折算「相对成本」——被否决，因为 rate 只有第三方实现的二手记录、且会把「不是钱的东西」显示成钱。**Consequences**：用户在 DSH 内看不到花费，需要去 OpenDesign 控制台看额度与账单；这是刻意的，不是缺陷。

**范围澄清（P1 额度面落地后）**：本 ADR 禁止的是**模型请求的金额**——价表、峰谷计价、会话费用、成本投影、
任何「这次调用花了多少钱」的折算。额度面板里的数字属于另一件事：`balanceUsd` 是控制面直接报的钱包余额，
窗口的 credits 按控制面自己的 `creditsPerUsd` 换算成展示当量（GLOSSARY 第七节「额度当量」）。两者都不是
对模型价格的重建，因此允许出现美元符号；模型分析页仍不得出现金额（只留 low/medium/high 与能力档标签）。
