# Triage 标签

技能以五个固定的 triage 角色说话；本文件把角色映射到本仓库 issue tracker 实际使用的标签串。

| 技能里的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整规格化，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

本仓库用本地 markdown tracker：角色串写在票文件顶部的 `Status:` 行，不创建 GitHub 标签。换 tracker 时只改「本仓库标签」列。
