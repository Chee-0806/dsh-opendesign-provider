## 浏览器 UI 验收（web profile，2026-10-21 午后）

在 `web` profile 装上同一 tarball，用浏览器真实点了一遍设置页、模型选择器、模型分析、额度卡与额度面板。**发现并修复 5 个真问题**：

| 问题 | 现象 | 修复 |
| --- | --- | --- |
| `opendesign/usage` Remote 404 | 额度卡永不出现；`/api/opendesign/usage` 404（analytics 正常） | `usage` 方法并回 `opendesignUsage` 同一个 Service（Typert 一个命名空间只解析一个 Service），删掉独立的 `OpenDesignQuotaService` |
| 点额度卡打不开面板 | 卡在、`selectPanel` 抛 `Cannot read properties of undefined (reading 'hasMainPanel')` | `layout.selectPanel` 是方法，改成在 layout 对象上调用（原来的解构调用丢了 `this`） |
| 额度进度条不可见 | 轨道色与白底同色（`bg-layer-1`），0% 时整条消失 | 轨道改用 `bg-module-platform`（侧栏卡与仪表盘都改） |
| 已用 <1% 显示 0% | 7 天窗口 83/150000 显示 `0%`，像没用过 | 已用>0 且取整为 0 时显示 `<1%`（补回归测试） |
| API Key「已设置」不说明来源 | CLI 登录态被误读成手填 Key | 徽标区分「配置内明文 / 凭据引用 / CLI 登录态」，设置页与模型卡共用同一判定 |

**未修、记录在案的 UI 观察**（不阻塞交付）：

- 「模型分析」首次读取要扫最多 100 个会话/20 万事件，本机 309 个会话时约 20–25 秒，期间只有「读取中…」没有进度或取消；「读取」是文字链接按钮。
- 分析表列宽按 `white-space:nowrap` 计算，窗口窄时最后一列（重试）被裁在右缘，只能横向滚动看到。
- 设置页「模型与上下文」「高级」没有分组折叠，12 个可见模型复选框 + 12 行按模型覆盖 + 4 个高级字段全展开，页面很长；按模型覆盖行距偏大。
- API Key 行是「说明文字 + 右侧控件」两列布局，与其他全宽输入字段不一致，说明文字被压成窄列。
- 模型选择器里 Open Design 分组的第一项在滚动时会被搜索框盖住（引擎插槽行为，非本插件样式）。
